# Snowmac

Weather on your Mac desktop: snow, rain, petals and fireflies drawn on a click-through overlay above every window and Space. Lives in the menu bar.

Status: early prototype (Core Animation emitters). Planned: Metal particles, weather landing on windows, Dock snow.

## Build and run

    swift build -c release
    .build/release/flurry

Needs macOS 13 or later and the Swift toolchain.
